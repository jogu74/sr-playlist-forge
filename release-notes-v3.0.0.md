# SR Playlist Forge 3.0.0

Version 3 is a new generation of SR Playlist Forge with a redesigned default interface and substantially expanded playlist, discovery, visual, and Quest workflows.

## Highlights

- New responsive dark interface with dedicated Playlist, Discover, Appearance, and Quest workspaces.
- Visual Browser, sortable List Browser, and community Playlist Browser with official Curated categories.
- Inclusive upload-date filtering, upvote/download sorting, and accurate current-playlist status in both song browsers.
- Live multi-song drag reordering with visual feedback and preserved relative order.
- Playlist icon and texture previews imported read-only from Quest or a local Synth Riders installation.
- Correct no-icon initial rendering with the original Bordas font when available.
- Modern Quest transfer, report, playlist-management, and song-management dialogs.
- Quest playlist reordering with preserved number gaps, optional compaction, verified backups, two-phase renaming, and rollback.
- Faster orphan-song detection using cached identities first, with determinate progress for remaining headset reads.
- Playlist Browser support for opening, merging, and saving community playlists.
- Remembered window placement and table-column widths.
- Safer downloads, bounded parsing, atomic local writes, single-instance protection, and expanded automated tests.

## Installation

Download `SR Playlist Forge 3.0.0 setup.exe` from the Assets section below and run it. Existing settings and the current editing session remain compatible.
